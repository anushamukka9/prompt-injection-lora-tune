# Dataset

`prompt_injection.jsonl` (2,000 records) and `prompt_injection_sft.jsonl`
(same records, chat-formatted) are fully synthetic. They were generated by
`src/pilora/dataset.py`, which is the source of truth; these files are
checked in so the repo is usable without rerunning the builder.

## How it was made

- Hand-written templates per category, with slots filled from fixed filler
  lists (actions, topics, languages) plus neutral politeness wrappers
  ("Please ", " Thanks!") that do not change the label.
- Deterministic: `pilora-build-data --seed 42` reproduces these exact files.
- Deduplicated by SHA-256 of the text.
- Stratified 80/10/10 train/val/test split within each category.

## Composition

| Category | n | Label | What it covers |
|---|---|---|---|
| obvious_injection | 500 | INJECTION | Direct overrides: "ignore previous instructions", fake system notices, DAN-style jailbreaks |
| subtle_injection | 500 | INJECTION | Indirect: hypothetical framing, tool-output injection, "for my novel", multi-step pretexts |
| benign | 600 | BENIGN | Ordinary requests: trivia, coding help, recipes |
| benign_edge | 400 | BENIGN | Tricky benign: *discussing* prompt injection, quoted instructions, code with instruction-like strings |

## Honest limitations

- Template-generated means limited linguistic diversity. A model that scores
  well here has learned the templates, not the wild.
- Labels are by construction, not by human rating. Edge cases were written
  to be unambiguous, which makes them easier than reality.
- No adversarial or adaptive attacks. Real prompt injection is an arms race;
  this dataset is a fixed target.
- English only.

Regenerate with a new seed for a fresh split, or extend the templates in
`dataset.py` to grow it. If you add real labeled data, document its source
and license here.
